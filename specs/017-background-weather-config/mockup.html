Fixed constraints from the spec: exactly five categories (sunny, mixed, cloudy, rain, snow); background and nav bar text always derived from one shared classification (FR-002); unrecognized config values fall back to "auto" (FR-008); last-known-good category is retained on fetch failure (FR-009).

  
Out of scope for this mockup: real animation timing/motion (drift speed, particle count, spawn cadence), the exact WMO-code→category mapping table, `prefers-reduced-motion` handling, and the mobile sub-nav weather row (same text, different position — not re-drawn here).

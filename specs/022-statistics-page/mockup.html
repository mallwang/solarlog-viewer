Fixed constraints: left-nav topic list is ~20% width on desktop (flex: 0 0 20%), collapses to a horizontal button row above the content on mobile per spec FR-001/FR-014. All five topics are independently linkable routes in the real app (mocked here via plain buttons, not real hash routes). Heatmap color scale is relative to each year's own min/max (FR-015); "worst" stats are always visible, no toggle (FR-016).

Out of scope for this mockup: real chart rendering (ApexCharts heatmap type and line/bar charts are represented as inline SVG/CSS-grid placeholders only), i18n/English copy (German shown to match the app's default), exact stat-tile responsive reflow below the 2-column mobile grid shown here, and the "not enough data yet" wording's final copy.

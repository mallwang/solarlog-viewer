Try it: hover your pointer over either icon above (current or forecast), or tab to it with the keyboard, to see its own tooltip reveal the full text. The "Hover previewed" state button forces both open for a static look without needing precise pointer placement.

Fixed constraints

  • Both indicators are compacted the same way: icon on top, current temperature or forecast range beneath, label/day-prefix text moved into the hover tooltip (FR-001, FR-003).
  • A vertical divider (border on the forecast indicator's leading edge) separates the two indicators (FR-008).
  • Each tooltip is exactly the same text previously shown inline for that indicator — the forecast tooltip keeps its "Heute:"/"Morgen:" prefix — no new wording (FR-004).
  • Each indicator's "unavailable" state stays visible by default, not hidden behind hover (FR-007) — see the Unavailable content-state button; current/forecast availability are independent.
  • Touch/keyboard equivalent: tapping or focusing an icon reveals its tooltip via :focus-within, the same interaction as hover (FR-006).

Out of scope for this mockup

  • Exact icon glyph per weather category (already defined in weather-icon.js, unchanged) — only sunny/rain glyphs are shown here for illustration.
  • Production/yield widget styling — shown only for layout context, unchanged by this feature.
  • Forecast day-switch logic (today vs. tomorrow) — unaffected, only its display shape changes.

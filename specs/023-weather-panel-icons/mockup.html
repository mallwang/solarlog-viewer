Forecast line — every combination

What changed

  • Current-conditions line: "Aktuell:" text prefix removed; a decorative icon now leads instead (FR-001–FR-003).
  • Forecast line: gains an icon; range reorders from "max / min" to "(low°C - high°C)"; prefix switches "Heute:" → "Morgen:" (and its data switches today → tomorrow) at a fixed local cutoff hour, default 18:00 (FR-004–FR-006, FR-014). See the second gallery below for every category on both sides of the cutoff.
  • Nighttime-only override: when "sunny" and it's after sunset/before sunrise, the current-conditions line shows 🌙 "Klar" instead of ☀️ "Sonnig" — the forecast line is never affected by time of day, only by the separate Heute/Morgen cutoff above (FR-011/FR-012). Try the "Night · clear" state above.
  • Unavailable state is unchanged in substance — no icon, existing fallback text/emptiness (FR-008); a forecast day whose data fails to load past the cutoff also falls back to this same empty state rather than showing a mismatched day (FR-015). Try the "Unavailable" state above.

Fixed constraints

  • Icons are decorative Unicode glyphs, aria-hidden="true" (FR-009) — the label text remains the sole accessible name.
  • Icon and label must never separate across a line wrap, at any width from 320px up (FR-010).
  • The Heute→Morgen cutoff hour is a fixed value in config.js (FORECAST_DAY_SWITCH_HOUR), not a user-facing setting — no settings UI is part of this feature.
  • The dashed outline and "reworked" tag above are review annotations only — not part of the shipped UI.

Out of scope for this mockup

  • Exact icon glyph choices beyond the five-category set + moon (☀️/⛅/☁️/🌧️/❄️/🌙) — final glyphs are a research.md decision, not a layout question.
  • Data-sourcing/network changes (the extra Open-Meteo sunrise/sunset fields) — no visual effect.
  • Production/yield styling (pulse dot, wattage, kWh figures) — shown only for layout context, unchanged by this feature.
